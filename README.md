# まいはら・まいばら年表オープンデータ

滋賀県「米原」の読み方、**「まいはら」と「まいばら」**に関する歴史をまとめた年表オープンデータです。

現在、

- 米原市 → **まいばら**
- JR米原駅 → **まいばら**
- 米原IC・米原JCT → **まいはら**
- 米原市米原 → **まいばらし まいはら**

と、同じ「米原」でも読み方が混在しています。

このデータでは、旧米原村、入江村、米原駅開業、米原町成立、米原IC/JCTの読み変更、米原市成立までの変遷を時系列で整理しています。

## データ

`maihara_maibara_timeline_with_sources.csv`

文字コード: UTF-8（BOM付き）

### 項目

| 項目 | 内容 |
| --- | --- |
| 年月日 | 出来事が起きた年月日、または期間 |
| 名称・出来事 | 自治体、駅、IC/JCTなどの名称や出来事 |
| 読み | その時点での「米原」の読み |
| 補足 | 背景や読み方に関する説明 |
| 出典 | 情報の出典 |
| 出典URL | 出典ページのURL |

## 主な出来事

- ～1889年：米原村では「まいはら」「まいばら」の両方の読みが存在
- 1889年4月1日：米原村などが合併し**入江村**成立
- 1889年7月1日：**米原駅（まいばら）**開業
- 1923年11月15日：入江村が町制施行し**米原町（まいはら）**へ
- 1980年：**米原IC（当初は「まいばら」）**開通
- 2001年6月4日：米原IC・米原JCTを**「まいばら」→「まいはら」**へ変更
- 2005年2月14日：**米原市（まいばら）**誕生

特に興味深いのが2001年の変更です。

約21年間「まいばら」と呼ばれていた米原IC/JCTが、旧米原町からの要望によって「まいはら」へ変更されたとされています。

ただし、

**なぜ2001年だったのか？  
誰が変更を提案したのか？  
どのような理由で変更を求めたのか？**

については、まだ決定的な資料を確認できていません。

## 情報募集中

2000～2001年ごろの次のような資料を探しています。

- 米原町から日本道路公団への読み方変更要望書
- 米原町役場内の起案・決裁文書
- 米原町議会会議録
- 「広報まいはら」
- 日本道路公団の名称変更資料
- 当時の新聞記事
- 当時の町職員、町議、道路公団関係者の証言

情報や資料をご存じの方は、IssueまたはPull Requestでお知らせください。

間違いの指摘、出典の追加、より正確な一次資料への差し替えも歓迎です。

## 出典について

- 米原市
- JR西日本
